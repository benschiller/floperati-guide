# Floperati guides: FLOP Network, as it really works

Field guides from [Floperati](https://floperati.com), written from our own runs on FLOP devnet. Every step, number, time and failure comes from what we actually did, with on-chain references you can check.

| Guide | What it covers | Web version |
|---|---|---|
| [Set up an AI agent on FLOP devnet](agents/) | Account, on-chain registration, a wallet with spend limits, a gateway key signed by the agent, paid inference, reporting the task on chain | [floperati.com/agents](https://floperati.com/agents/) |
| [Set up a FLOP devnet miner on a rented GPU](miner/) | A rented RTX 5060 Ti on Vast.ai running FLOP's official miner pack, calibration, the first paid call, keeping it serving, and our own agents paying it in channels they open on chain | [floperati.com/miner](https://floperati.com/miner/) |

A FLOP miner is a GPU that serves AI inference to agents and is paid on chain. It does not mine cryptocurrency.

**Status:** FLOP devnet, runtime 1014031, 17–22 Nov 2026. FLOP testnet is planned for 24 Nov 2026 (tentative, per Flop Labs); we'll update these guides when we've run them there.
